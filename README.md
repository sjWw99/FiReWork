# FiReWork 2.8.0

Нативное Windows-приложение на Rust (Win32 через `windows-sys`, без тяжёлых
зависимостей). Весь интерфейс рисуется напрямую через user32/gdi32; иконка,
манифест `requireAdministrator` и версия вшиваются через `build.rs`.

## Структура

| Файл | Назначение |
|------|------------|
| `src/main.rs` | Точка входа, цикл сообщений, самоповышение прав (UAC), шрифты, общее окно. |
| `src/win.rs` | Базовые обёртки WinAPI, глобальное состояние, шрифты, классы окон. |
| `src/theme.rs` | Тема «liquid glass» (светлое стекло, блики, градиент) + упрощённый режим; owner-draw карточек, категорий, вкладок. |
| `src/layout.rs` | Категории и карточки (`define_categories`), раскладка, отрисовка главного экрана. |
| `src/reg.rs` | Прямая работа с реестром через Win32 (чтение/запись всех типов, обход `DisableRegistryTools`). |
| `src/editdlg.rs` | Нативный диалог «Имя / Тип / Значение». |
| `src/procwin.rs` | Окно «Процессы»: таблица, поиск, контекстное меню. |
| `src/autostart.rs` | Окно «Автозагрузка»: вкладки Run/Winlogon/службы/задачи. |
| `src/settings.rs` | Окно настроек: «поверх всех окон», упрощённый режим. |
| `src/outwin.rs` | Окно потокового вывода для долгих действий (SFC/DISM/CHKDSK). |
| `src/exec.rs` | Запуск команд, логирование, привилегии, IFEO. |
| `build.rs` | Встраивание иконки, манифеста и версии. |

## Сборка

Нужен [Rust](https://rustup.rs) (toolchain `x86_64-pc-windows-gnu` или `-msvc`).

### Windows
```bat
build.bat
```

### Linux / macOS (кросс-компиляция)
```bash
./build.sh
```

### Вручную
```bash
cargo build --release
# результат: target/release/FiReWork.exe
```
